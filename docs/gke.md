# Gemma Knight Edition (GKE)

An enhanced version of the original game that stays true to the original
content, but makes larger "above intended" improvements including control
shortcuts, dynamically created map, built-in speedrun timers, status bar
centering, selective balance changes, and a few secrets scattered throughout.
It's intended to be a personal expression tied to fast and tight gameplay.
